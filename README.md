# Grupo GB - Terceirização de Serviços 🏢🤝

Este repositório contém o código-fonte do site institucional do **Grupo GB**, uma empresa especializada em soluções estratégicas de terceirização. O projeto foi desenvolvido para apresentar a solidez da marca e facilitar o contato de empresas que buscam eficiência operacional.

## 🔗 Demonstração
Acesse o site em: [https://lucasknd.github.io/Site-Institucional-GrupoGB/](https://lucasknd.github.io/Site-Institucional-GrupoGB/)

## 📍 Sobre o Projeto
O site do **Grupo GB** foca na autoridade e profissionalismo necessários para o setor de prestação de serviços. Os principais pilares do projeto são:

* **Apresentação de Serviços:** Divisão clara das áreas de atuação da empresa.
* **Credibilidade:** Design sóbrio que transmite confiança ao cliente B2B.
* **Conversão Direta:** Facilidade para solicitação de orçamentos e parcerias.

## 🛠️ Tecnologias e Ferramentas
* **HTML5 & CSS3:** Estrutura semântica e estilização moderna com foco em responsividade.
* **JavaScript:** Implementação de componentes interativos e melhoria na experiência do usuário.
* **Google Tag Manager (GTM):** Configurado para tagueamento de eventos e análise de tráfego qualificado.

## 🚀 Funcionalidades
* **Interface Responsiva:** Navegação fluida em desktops, tablets e smartphones.
